# Adam Suvai Zone — Heritage South Indian Website

Official responsive restaurant, combo menu, online ordering, and catering website for **Adam Suvai Zone** (No. 36, Rangan St, T. Nagar, Chennai - 600017).

## Project Structure
```text
adam-suvai-zone-website/
├── index.html          # Main landing page & interactive layout
├── css/
│   └── styles.css      # Turyaa Chennai-inspired luxury hospitality theme
├── js/
│   ├── menu-data.js    # Complete restaurant menu & 3 combo menus with pricing
│   └── app.js          # Filtering, search, estimate cart, WhatsApp & modal logic
├── assets/
│   ├── logo.svg        # Official Adam Suvai Zone circular crest logo
│   └── halal-badge.svg # 100% Halal seal
├── .vscode/
│   └── settings.json   # VS Code Live Server configuration
└── README.md
```

## How to Run in VS Code
1. Extract the ZIP folder and open `adam-suvai-zone-website` in **Visual Studio Code**.
2. Install the **Live Server** extension (by Ritwick Dey) if not already installed.
3. Right-click `index.html` and select **"Open with Live Server"** (or click **Go Live** in the bottom-right status bar).
